# voice-showcase

Conversational voice demo for landing and dashboard previews — greeting, name, then a menu (weather, count, recipes, fun facts).

## Build

```bash
npx @voicethere/agent build --entry templates/voice-showcase/agent.ts --outfile dist/agent.js
```

## Sources

- `agent.ts`, `conversation.ts`, `delivery.ts`, `weather.ts`, `recipes.ts`, `fun-facts.ts`
