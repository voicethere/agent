# About this agent

This is a sample document. It tells the agent what it is: a voice and chat assistant built from the VoiceThere llm-agent template.

## How to replace this file

Delete this text and write what your agent should know: product facts, prices, opening hours, policies. Use one heading per topic, because the agent splits every file by heading and searches the pieces. Keep each section short and self-contained, around 300 words at most.

## How to add more files

Put more Markdown files in this folder, import each one in agent.ts and add it to the documents list. When a file changes, the next start indexes it again. Files that did not change are not embedded a second time.
