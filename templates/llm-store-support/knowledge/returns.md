# Returns and exchanges

## Return window

You can return unused gear within 60 days of delivery for a refund to the original payment method. Items must be clean, unworn and in the original packaging, with tags attached. Tents must not have been pitched on dirt.

## How to start a return

Open the order on the website and choose Start a return, or contact support with the order number. We email a prepaid return label for orders shipped within the United States. Refunds are issued within five business days after the warehouse receives the package.

## Exchanges

For a different size or color, start a return and place a new order. We do not hold stock for exchanges, so ordering the new item first avoids a sellout.

## What cannot be returned

Used fuel canisters, opened water treatment tablets, socks and base layers that have been worn, and gift cards cannot be returned. Items damaged on arrival are replaced at no cost; send photos to support within seven days.
